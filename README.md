# Raccolta 2026 – Olivenernte Status

Statische Seite für GitHub Pages.

- index.html – öffentliche Status-Seite
- admin.html – Eingabe (PIN)
- config.js – hier die Apps-Script-URL eintragen (leer = Demo-Modus)
- apps-script/Code.gs – Backend für Google Sheets (wird NICHT auf GitHub ausgeführt, nur in Google Apps Script einfügen)

Wichtig: Die Datei .nojekyll muss mit hochgeladen werden, sonst blendet GitHub Pages den Ordner _ds aus.
